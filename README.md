# Week-2-SQL-Database-Querying
SQL &amp; Database Querying – Week 2 Internship Project | SQL Fundamentals, Aggregate Functions, Joins, Subqueries, CASE Statements, and Query Documentation.
SQL and Database Querying Internship Task

Project Overview

This project demonstrates SQL skills using a retail sales database. It includes queries for retrieving, joining, grouping, aggregating, and analyzing data to answer practical business questions.

Database

Database name: retail_sales

Tables used: employees, customers, orders

The SQL script assumes that the retail_sales database and the required tables/data already exist.

Topics Covered

SELECT, WHERE, and ORDER BY

Aggregate functions such as COUNT(), SUM(), and AVG()

GROUP BY and HAVING

Joins to combine related tables

Subqueries and CASE statements

Window functions such as RANK(), ROW_NUMBER(), DENSE_RANK(), and OVER()

Common Table Expressions (CTEs)

Business questions documented in SQL comments

Business Purpose

The queries are designed to explore sales and customer data, compare results across groups, rank records, and summarize information that can support business analysis.

Files

retail_sales_internship_final.sql — SQL queries and explanatory comments.

How to Run

Open MySQL Workbench or your preferred MySQL client.

Make sure the retail_sales database and the required tables/data are available.

Open the SQL script.

Execute the queries you want to review.

Check the result grid for each query.

Notes

This project is intended for query practice and analysis.

The script is query-focused; it is not intended to delete or recreate the database tables.
